# PortBridge UI 设计规范

正式工作流沿用本规范的深浅主题、字体、分隔条和状态语义，增加第四导航及原生QtNodes画布。具体节点库/参数/结果/日志与小窗口折叠规则见 [工作流UI设计](12-workflow-ui-design.md)；真实实现/修复前后与设计原型对照见 [原生对照](../validation/workflow-implementation/comparison.html)。软件125/150%记录实际窗口/画布/DPR，不替代物理WindowsDPI验收。

## HTTP / WebSocket 手动工作台（http-ws-1）

在既有主题与导航内增加36DIP模式栏，手动协议页隐藏原始连接侧栏并改用200DIP独立方案库。保留名称/URL/动作的明确层级，参数/请求头/认证/Body/设置可浏览，活动期间锁定握手配置。请求与结果可拖动分隔，WS消息可离线准备。状态、空态、分页范围及历史省略均使用真实值；默认结果视图、复制和导出采用有界凭据遮蔽。原生100/125/150%及1024紧凑界面和部署1280/1440截图见 [手动协议界面浏览](../validation/manual-protocol/gallery.html)，完整规则见 [14-manual-protocol-design.md](14-manual-protocol-design.md)。

## 1. 设计目标

面向设备联调的桌面工作台：连接参数随时可见，数据与原始字节联动，发送与记录状态清楚。高速场景用有限显示样本、吞吐和丢失诊断提供可判断的信息。

默认采用深色石墨背景和低饱和青绿色主色，同时提供浅色主题。视图以分隔线、工具条和面板组成，避免将每项统计包装成独立浮动卡片。正文中文，协议名、字节、端点与单位保留标准表达。

## 3. 布局

1440×1000 原型布局：顶部导航 60px，底部状态栏 28px；左工具轨 54px、连接面板 232px，剩余为工作区。工作区右侧检查器 246px，中央数据列表占剩余空间。

工作区自上而下：标题与模式/记录 → 四项指标 → 吞吐趋势/队列 → 数据/诊断工具条 → 数据和检查器 → 发送区。接收区与发送区使用可拖动的纵向分隔条，共享可变空间，参数、发送按钮和连接状态不随数据列表滚动。四种通信方式统一使用全宽多行发送编辑器，格式和周期选项移到编辑器下方；可展开编辑并恢复之前分配。小于 850 DIP 高度或展开编辑时折叠趋势图，实时指标继续显示；正常窗口恢复趋势图。

| 布局元素 | 原型建议 | Qt 实现原则 |
| --- | --- | --- |
| 顶部导航 | 60px | 菜单/动作统一管理，视觉参考原型，不必仿造浏览器 |
| 工具轨 | 54px | 可用窄 QWidget/QToolBar |
| 连接侧栏 | 232px | 默认宽度可调整，设置最小宽度 |
| 详情侧栏 | 246px | 使用 QSplitter，允许扩展以阅读字节 |
| 表格行 | 32px | 以字体和平台密度调整，不硬编码每个像素 |
| 输入/按钮 | 28–34px | 遵循 Qt DPI 缩放；关键操作清楚可点击 |
| 主区边距 | 22–25px | 统一布局间距，紧凑但不堆叠 |

Qt 使用 DIP 和布局约束；原型 CSS px 是评审尺寸，不能直接转换成物理像素坐标。

## 5. 字体与图标

- UI：Windows 优先 Segoe UI / Microsoft YaHei UI；正文以 12–13 DIP 起步，标签 11–12 DIP，避免把浏览器压缩预览的微小辅助字作为 Qt 正文字号。
- 数值：主要指标 28–32 DIP，等宽字体并对齐单位。
- 字节、时间和端点：Cascadia Code 或 Consolas；跨平台选择实际存在的等宽字体。
- 图标：16–20 DIP，线性、单色、风格一致；功能按钮有 tooltip 和可访问名称。
- 单位：MB/s 为十进制有效负载；MiB 为缓存容量；Gbps 为接口速率；不可混写。

## 6. 组件规则

### 数据列表

列：记录序号、软件时间、方向、来源/连接、字节长度、内容预览。长度右对齐；HEX 不自动折行导致行高变化。过长预览省略，完整字节由检查器、复制及样本导出访问。列表水平滚动只在自身范围内发生。

### 字节检查器

OFFSET / HEX / ASCII 区分明确；正式版 HEX/ASCII/UTF-8 使用页签，按 4096 字节分页并允许页内滚动，页码与范围可见，完整原始字节可复制。ASCII 非可打印字符显示点，中文等内容在 UTF-8 页签解码展示；新记录首屏有效且包含非 ASCII 字符时自动切换。UTF-8 以完整字符处理分页边界，不重复字符；无效字节警示并保留原始 HEX。原型仅强调前 4 字节，不假设已正确识别协议帧头；文本预览增加 RX 绿色、TX 橙色、区别明显的底色与 ▼/▲ 方向标识、时间和端点，并提供原文、HEX 分行和 JSON 缩进选择。

### 指标与趋势

RX 速率和 PPS 分开。TCP 显示连接与接收块/字节，不把数据块数量当业务帧数。未配置协议序号分析时显示“不适用/未知”，不能显示虚假零丢帧。

### 主动作

接收诊断只保留实测接收、截断、应用队列、记录及显示计数，移除没有数据来源的发送端/网卡“未知”占位；普通文本不声明可直接测出网络丢包。连接动作在参数旁，记录动作在工作区右上，发送动作在编辑器旁。停止记录和周期发送均有文字状态，不只依赖按钮颜色。清空显示不会停止通信和记录。

### 异常提示

参数错误就地呈现；运行异常在数据区上方横幅呈现并在诊断中提供证据；短期操作结果使用非阻塞提示。长期过载不能仅靠短暂 toast。

## 7. Qt Widgets 组件映射

| 原型区域 | 推荐 Qt 组件 | 要点 |
| --- | --- | --- |
| 应用框架 | QMainWindow、QAction、QMenuBar/QToolBar | 快捷键和操作状态统一 |
| 主导航 | QStackedWidget + 导航按钮 | 工作台、文件、命令切换不停止后台通信 |
| 主分栏 | QSplitter、QWidget + 布局 | 保存分栏宽度；不要绝对定位 |
| 连接方案 | 自绘 QToolButton 当前卡片 + QMenu/QWidgetAction 搜索列表 | 卡片 64 DIP；列表按需打开、最多六行后滚动，搜索后收缩高度；浏览保持运行、单独返回活动方案 |
| 连接参数 | QStackedWidget + QFormLayout | 各传输独立表单；使用验证器 |
| 指标条 | QWidget + QLabel + 水平布局 | 统计快照批量更新 |
| 吞吐趋势 | 自绘 QWidget/QPainter | 有限历史点、固定频率绘制；不需要首版引入大型图表库 |
| 原始记录列表 | QTableView + QAbstractTableModel | 有界缓存；批量插入，避免逐包创建 QTableWidgetItem |
| 字节详情 | 自绘字节视图或只读 QPlainTextEdit | 只格式化选中的有限字节，不转整条高速流 |
| 诊断 | QWidget + 行布局或 table model | 未知与零分开；计数有来源 |
| 发送编辑器 | 全宽 QPlainTextEdit + 纵向 QSplitter | 高度至少 96 DIP，可拖动/展开；禁止无效 HEX；显示编码后的长度 |
| 周期/次数 | QCheckBox、QSpinBox/QComboBox | 运行中锁定配置；实际调度交给通信核心 |
| 采集设置 | QWidget + QFormLayout | QFileDialog 选择目录，运行中策略锁定 |
| 新建/命令编辑 | QDialog | 验证内联，默认不会连接或发送 |
| 状态栏 | QStatusBar | 活动连接、RX/TX、记录状态 |
| 主题 | QPalette + 克制的 QSS | 样式集中，保留系统缩放与焦点可见性 |

不要用 QWebEngineView 嵌入 HTML 来实现正式主界面。本 HTML 是设计评审载体，正式应用按 Widgets 重新实现。

## 8. 高速 UI 约束

1. UI 获取统计快照和有限样本，更新频率建议 10–30 Hz 起步，实测调整。
2. 表格、HEX 和曲线共享 UI 工作量预算，不逐包发 queued signal。
3. 抽样、暂停及显示裁剪不会被计为网络接收丢失；原始记录是否完整另行判断。
4. 操作通信状态使用异步命令；GUI 不同步等待 socket、串口或磁盘。
5. 显示采集容量预估与记录异常；不根据漂亮的吞吐图推断无损。
6. 异常时仍能停止任务和查看诊断，不能以无限更新占满事件循环。

## 9. 评审清单

- 四种传输名称、字段和状态是否符合实际语义。
- 服务端发送目标是否明确；UDP 是否误示对端在线。
- 浏览方案是否保留活动绑定、周期和记录，返回后是否恢复数据；显式停止、断线、启动另一方案是否结束旧任务。
- HEX 错误、未知系统统计、显示抽样是否明确。
- 深色/浅色是否保留方向、状态和告警的可辨识性。
- 桌面窗口、125%/150% DPI、中文字体下是否溢出或文字过小。
- 网络负载与 UI 更新是否独立；正式版必须用真实数据压测。

本次浏览器验证与截图记录见 `09-ui-prototype.md`；Qt 字体/DPI、系统菜单与原生窗口行为尚未验证。

## HTTP 项目与环境（http-project-1）

在原生HTTP页保留请求/响应分割布局，左栏增加项目、分类和环境管理。变量采用有界表格、类型编辑器、敏感遮蔽和来源/更新时间；认证独立对话框，提取规则沿用启用/名称/值编辑。默认分类为全部请求，编辑器保存到分类不使列表看似丢失。三档软件缩放和深浅主题见 [原生图集](../validation/http-projects/gallery.html)。

断言以启用、来源、字段、关系、预期JSON和解析提示表呈现。独立对话框勾选/排序请求，默认遇错停止；结果页签逐步显示一般原因并省略敏感实际/预期值。深浅主题和100/125/150%原生软件缩放见 [图集](../validation/http-sequence/gallery.html)。
