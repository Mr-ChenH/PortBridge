# PortBridge 界面结构与交互地图

## 1. 范围与导航

本设计对应现有首版需求、2.5G高速方案和HTTP/WS手动调试扩展。包含调试工作台、采集文件、命令库、正式工作流及小型编辑对话框。调试工作台内部增加“通信调试 / HTTP / WebSocket”，原始通信仍采用共用工作区，按串口、TCP客户端、TCP服务端、UDP切换连接参数。HTTP/WS使用独立请求方案，不扩充原始传输枚举。

左侧常驻一张当前方案卡片，点击后打开按名称、协议或地址搜索的方案列表；列表最多显示六行，其余滚动查看，筛选后高度随结果数量缩小。首版仅一个活动连接。浏览其他方案保持当前连接、周期发送和记录，卡片下方按需出现“返回运行方案”，返回后恢复其数据与状态；底部提示后台活动端点。只有主动启动另一方案、显式断开、编辑/删除活动方案、导入替换配置或关闭窗口时结束旧会话。浏览视图保持独立，不把旧会话统计、错误或字节归入其他方案。

主导航：调试工作台 → 采集文件 → 命令库 → 工作流。导航或浏览连接方案不结束活动通信；工作流页隐藏旧连接侧栏、离开恢复通信分隔布局。主动运行流程根据资源计划确认保留借用或替换当前活动连接；运行期间阻止工作台/命令/周期发送争用，暂停仅阻止后续步骤。顶部与左侧工具栏为相同导航的文字/图标入口。工作流的节点库—画布—参数/上次结果—日志/变量结构、模板/文件/草稿退出及紧凑折叠详见 [工作流UI设计](12-workflow-ui-design.md)；HTTP/WS在流程中按结构化响应/完整消息操作。

## 2. 工作台

### 目的

完成参数配置、建立连接、收发调试、检查原始数据、观察高速负载及启动记录。

### 区域

| 区域 | 内容 | 关键操作 |
| --- | --- | --- |
| 左侧当前方案卡片 | 名称、通信类型、端点摘要、活动状态 | 点击打开搜索列表、按需返回运行方案、新建及更多管理操作 |
| 左侧连接配置 | 根据传输类型显示参数 | 连接/断开、绑定/解除、监听/停止 |
| 工作区标题 | 方案名称、状态、实际端点 | 普通/高速切换、开始/停止记录 |
| 指标条 | 接收速率、包率或连接数、序号缺失或应用丢弃、记录状态 | 观察异常并进入诊断 |
| 吞吐趋势 | 最近时间段的有效负载 MB/s，应用队列容量 | 判断突发与积压；原型标注模拟 |
| 中央数据区域 | 时间、方向、来源/连接、字节长度、预览 | 搜索、选中、HEX/文本、暂停、清空、导出样本 |
| 右侧检查器 | 字节详情/采集设置 | 检查偏移、HEX、ASCII；配置原始采集 |
| 底部发送区 | 输入内容、发送格式、换行、周期及次数 | 发送、停止周期、载入命令 |
| 底部状态栏 | 连接、RX/TX、记录状态 | 原型另提供独立模拟场景切换 |

### HTTP / WebSocket 手动工作台

36DIP模式栏切换任务；HTTP/WS隐藏原始连接侧栏，使用200DIP独立请求库。右侧上方为名称、URL及明确的发送/连接动作，编辑页签包括参数、请求头、认证、Body（HTTP）和设置。下方为有界时间线及可调结果分隔区；HTTP提供Body/JSON/Headers/HEX，WS提供完整消息与HEX、离线可编辑的消息区、发送与关闭参数。

页面切换、载入和编辑保持静默并维持既有活动。HTTP/WS、原始会话和工作流之间启动不兼容活动时明确确认，确认后复核epoch/配置/运行身份。预览及默认复制/导出遮蔽凭据，原字节独立保留；暂停显示不停止接收，历史省略不冒充网络丢包。详细交互与预算见 [手动协议设计](14-manual-protocol-design.md)。以下连接参数、采集、完整原始HEX复制与周期发送描述属于“通信调试”。

### 串口参数

设备名称（支持输入）、波特率、数据位、校验位、停止位、流控。设备信息缺失不阻断连接。开关动作使用“打开串口/断开连接”，设备拔出后进入未连接状态并停止发送任务。

### TCP 客户端参数

目标 IP/域名、目标端口、本地网卡地址；动作是“连接设备/断开连接”。正式实现增加异步连接中状态，支持取消；超时信息出现在参数旁。

### TCP 服务端参数

本地监听地址、端口。监听后出现客户端列表及发送目标（指定客户端、广播）。数据列表显示每条连接的来源，右侧显示当前选中记录的连接信息。正式版本内部采用独立连接 ID，不能仅用 IP 判断同一连接。

### UDP 参数

本地绑定地址、本地端口、发送目标地址、目标端口。动作使用“绑定端口/解除绑定”；“已绑定”不等于对端在线。绑定/关闭仅更新状态，不生成 UDP 数据样本/原始采集的 SYSTEM 消息，也不发业务数据报；错误、发送拒绝、截断诊断仍保留。每条真实数据记录保留来源和数据报长度。

### 普通与高速模式

| 行为 | 普通调试 | 高速采集 |
| --- | --- | --- |
| 显示内容 | 详细记录及文本/HEX | 有限数据样本 + 吞吐/包率/队列状态 |
| 数据含义 | 串口/TCP 为读取块，UDP 为数据报 | 保持相同含义，不以抽样伪装完整接收 |
| 显示提示 | 显示缓存有限 | 固定提示抽样策略，未展示不计接收丢失 |
| 记录 | 与接收和显示独立 | 原始二进制与索引；离线导出可读格式 |
| 切换模式 | 保留当前连接 | 不自动开启或停止原始记录 |

原型普通模式仍使用小型模拟数据集，不能证明完整流量展示性能。

## 3. 数据样本与字节详情

选中一行后，右侧同步更新时间、来源、长度，提供 HEX / ASCII / UTF-8 页签。完整原始字节每 4096 B 分页，页内可滚动；页码与当前字节范围明确可见，ASCII 非可打印字节显示点，中文在 UTF-8 页签查看；首屏包含有效 UTF-8 非 ASCII 字符时自动切到 UTF-8。文本分页在起始字节所在页完整显示跨界字符、下一页跳过续字节；无效 UTF-8 明确提示，控制字节转义显示，HEX/ASCII 字节范围不变。选择另一条记录或清空时重置分页。复制使用完整原始 HEX。文本预览以绿色 RX、橙色 TX 及不同底色和方向标识 区分收发，包含时间、端点和长度，支持 UTF-8 原文、HEX 分行、有效 JSON 对象/数组缩进；无效或不完整 JSON 保留原文。

HEX/文本显示与发送格式独立。UDP 已绑定后直接使用发送区填写的 IP/域名及端口发送，不再需要“应用目标”或客户端选择；编辑目标及保存方案不发送 UDP 业务数据，排队请求保留各自的目标。搜索按来源、HEX 字节或解码文本过滤当前显示缓存，不改变原始接收和记录。

暂停显示：冻结当前视图；接收、计数和记录继续。恢复时告知暂停期间省略样本数量。清空只清显示缓存；正式实现独立提供“重置统计”，不能复用清空动作。

## 4. 丢失诊断

按实际可观察数据展示：应用接收 → 接收截断 → 应用队列丢弃 → 原始记录失败 → 显示抽样/暂停，页面名称为“接收诊断”。发送端总量和网卡/内核计数没有数据来源，移除两个固定“未知”占位；说明普通报文不能直接判断网络丢失，连续 uint64 序号需显式启用才能分析缺失。

- 仅有协议或测试数据序号时，才展示序号缺失及缺失率。
- UDP 有限观察窗口后区分缺失、乱序、重复，原型提供模拟说明。
- 未获得系统级统计时显示“未知”，不能显示 0。
- 记录未开启时，失败计数 0 不代表记录完整。
- TCP 未配置业务分帧/序号时，不显示虚假的端到端丢帧结论。
- 队列丢弃、记录丢失和显示抽样属于不同结果，分别展示。

## 5. 采集设置与文件页

右侧“采集设置”：目录、文件大小轮转、采集时长、按当前速率估算的每小时容量、磁盘空间/持续写入能力。正式实现空间和速度指标必须有来源；未知时不预设正常。

运行中锁定当前记录文件策略，停止后允许修改。开始记录要求存在活动连接。主按钮与指标条同时显示记录状态，异常采用横幅和文字提示。

采集文件页展示名称、通信类型、开始时间、时长、容量、结束状态及原始记录/索引信息。原型只导出小型模拟 JSON 样本，正式产品再接入文件打开、完整性检查及离线导出。

## 6. 命令库和发送区

命令包含名称、格式、内容。命令库提供添加、删除、载入工作台；快捷命令亦只载入，不自动发送。载入后格式和内容一起更新，用户检查后发送。

发送区：四种通信方式使用同一全宽多行编辑器，高度可通过接收/发送分隔条拖动调整，亦可临时“展开编辑 / 收起编辑”恢复先前空间分配。格式、编码、换行、周期和次数置于输入框下方；调整布局不发送数据、不改变编辑内容或通信。区域大小随正常布局保存，启动不恢复临时展开。HEX 或 UTF-8，附加无/CR/LF/CRLF，实时显示编码后字节数；非法 HEX 和奇数位禁用发送。断开连接禁用发送。

周期：间隔和持续/有限次数，按钮进入“停止”状态。运行中锁定内容、格式、换行、间隔及次数；取消周期、点击停止、断线或主动启动其他方案均结束任务；仅浏览方案不结束任务。原型提供 10/100/1000 次；正式 Qt 控件使用可输入次数及合理上限。

## 7. 对话框

- 新建连接方案：名称、通信类型；创建后未连接，用户设置参数后启动。
- 添加命令：名称、格式、内容；HEX 校验不通过时显示内联错误。
- 原型说明：模拟边界、快捷键和参考项目链接；不进入正式产品业务导航。

## 8. 状态覆盖

| 状态 | 设计 | 原型覆盖 |
| --- | --- | --- |
| 无显示数据 | 空状态提示不影响连接/记录 | 清空后可见 |
| 未连接 | 标题和状态栏明确状态；发送/记录禁用 | 浏览未运行方案或连接中断 |
| 参数错误 | 字段附近错误文案 | 非法 IP/端口/波特率 |
| HEX 错误 | 编辑器下方提示及发送禁用 | 非法字符/奇数位 |
| 接收过载 | 横幅、队列水位、应用丢弃 | 场景切换 |
| 记录变慢 | 横幅、记录状态、写入不足 | 场景切换且记录运行 |
| 显示暂停 | 暂停按钮变恢复，省略数可见 | 可交互 |
| 异步连接中/取消 | 连接按钮变取消，字段锁定 | 规范覆盖，原型模拟立即建立 |
| 设备拔出/权限不足 | 参数区域错误及系统事件 | 后续真实 Qt 实现 |
| 原始记录空间不足 | 明确失败/停止，不宣称完整 | 后续文件系统接入 |

## 9. 窗口与键盘

推荐桌面工作尺寸 1440×900 及以上，Qt 首版最低窗口候选 1100×760 DIP，并按用户屏幕调整。1024 宽原型收起连接面板；窄屏仅用于浏览设计，不是移动端产品承诺。

支持 Tab 聚焦、Enter 激活按钮、Ctrl+K 搜索、Ctrl+Enter 发送/停止周期、Escape 关闭对话框。数据表可用方向键移动焦点并用 Enter 选择。正式 Qt 增加上下行直接选择、Ctrl+Shift+R 记录及可发现的菜单快捷键。
