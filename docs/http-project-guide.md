# HTTP 项目与登录联调

“项目设置”和“配置环境”打开同一配置窗口；真实界面见 [图集](validation/http-configuration/gallery.html)，重构与验证见 [报告](reviews/http-configuration.md)。

HTTP 工作台支持本地项目、文件夹分类和独立环境。创建或切换项目、配置变量、保存/导入请求都不会发送通信；发送仍由“发送请求”或Ctrl+Enter明确发起。

## 配置一个登录闭环

1. HTTP左侧“管理 → 新建项目”，例如“会员服务”。用分类栏加号建立“认证”和“会员”文件夹。
2. 点击“配置环境”，在“服务地址 · base_url”填入服务地址，例如 `http://127.0.0.1:8080`；环境名称及其他环境变量也在这一页编辑，点击“保存配置”。运行前请自行启动服务；示例地址不会启动服务。
3. 新建“登录”请求，选择POST，URL填 `{{base_url}}/login`。认证选择“无认证”，Body按服务要求配置。在“响应提取”页签添加启用的一行：名称 `access_token`，值 `$.data.access_token`。
4. 保存请求到“认证”文件夹。点击“发送请求”。假设服务返回2xx与 `{"data":{"access_token":"..."}}`，该值会写入当前环境的运行变量。路径不存在、非2xx、网络失败、取消或操作身份过期时保留原值，并显示原因。
5. 点击“项目设置 → 公共认证”，选择“Bearer Token（令牌）”，从变量下拉框选 `{{access_token}}`，或直接填写引用。只填Token，不加Bearer前缀；工具自动生成。新建“查询会员”，URL `{{base_url}}/users/me`，认证选择“继承项目”。保存到“会员”文件夹。点击发送后，实际请求带 `Authorization: Bearer <登录得到的值>`。

Bearer和Basic可在请求级覆盖，也可明确选择无认证。手工Authorization与生成的认证头重复时拒绝发送，避免无提示覆盖。文件夹用于归类，公共认证来自项目。可在“管理”中重命名/删除分类；删除分类将请求移至“未分类”，保留内容和请求ID。

项目示例 [login-reuse.pbhttp-project.json](examples/login-reuse.pbhttp-project.json) 提供“登录并提取token”和“查询当前会员”两条模板。导入后修改base_url、username并填入敏感password；请求路径和响应结构需与自行启动的服务一致。它不会启动服务、登录或发送请求。

## 环境与变量

项目之间、环境之间的运行值互相隔离。环境下拉框选择本次联调的变量上下文；切换环境保留当前请求模板，活动请求期间锁定切换。可在“管理”创建、复制或删除环境，新建/复制后直接打开配置。“配置环境”也可修改当前环境名称；复制保留普通定义，省略敏感值与全部运行值。环境只影响显式的变量引用，例如 `{{base_url}}/users/me`；固定URL不会随环境改变，也不会自动登录。

“项目设置”统一提供四个区域：

| 配置区 | 用途 |
|---|---|
| 当前环境 | 编辑名称、服务地址base_url和仅属于此环境的定义。 |
| 项目变量 | 配置所有环境共享的默认定义；同名环境定义可覆盖。 |
| 公共认证 | 配置请求可继承的无认证/Bearer/Basic；按类型显示字段及脱敏的请求头示意。 |
| 生效变量 | 查看当前已保存配置实际使用的值、来源和运行更新时间；敏感值始终遮蔽。 |

配置窗口先编辑草稿，“保存配置”一次提交名称、定义、认证与运行清除；“取消”放弃修改。校验失败或打开后上下文变化时保留旧状态。新建环境是单独的明确操作：取消随后的配置仍保留已创建环境，显示服务地址未配置。

在“生效变量”选中运行值并点击清除，保存后才生效；取消会保留原值。清除后按优先级回退到环境/项目定义，没有定义时引用变为未定义。运行值不会出现在定义编辑框中，查看与保存配置不会把登录提取值变成长久定义。

变量名称为字母/数字/下划线标识，首字符须为字母或下划线，区分大小写。支持文本、数字、布尔、JSON对象/数组；优先级为“当前环境运行值 > 当前环境定义 > 项目定义”。项目变量也可通过“管理 → 项目变量与共享默认值”直接打开同一设置页；项目敏感值只进入当前环境运行期，不跨环境共享。敏感定义未填写新值时保留已有运行值，可在“生效变量”清除；编辑定义与查看运行值分别承担明确用途。

URL、query、headers、Bearer/Basic以及各Body模式支持 `{{变量名}}`。路径/query和urlencoded值按所在字段编码，保留加号、百分号、空格、中文和emoji。JSON中 `"{{text}}"` 会转义字符串；`{"count":{{count}}}` 可保留数字/布尔/对象类型。未定义、循环、超限或展开后产生非法URL/请求头/JSON时在网络前拒绝；请求快照不随之后编辑改变。

保存的是模板，未登录也可以保存或导出。输入真实token/password等凭据默认被遮蔽；使用变量引用可以在下次登录后复用模板。响应JSON提取支持点路径与数字数组索引，例如 `$.data.items[0].id`；响应头可填 `header:X-Session`。本期可视化提取默认将值视为敏感运行值，不提供任意脚本、自动重登或刷新。

## 文件与兼容

“管理 → 导出项目”导出当前项目全部已保存请求、文件夹、认证模板和环境定义到 `.pbhttp-project.json`，版本2；省略敏感变量值及响应运行值。未保存的编辑不包含在项目导出中。“导入项目”先验证完整文件，再创建独立项目和新ID；不会通信或执行登录。单个请求的原 `.pbhttp.json` 格式仍兼容，WS继续使用独立方案库。

已有HTTP版本1方案库迁入“默认项目”，保留请求ID和原始旧库。新的项目与请求统一保存；写入失败保留旧状态。损坏/未知版本配置保留原数据并提示，避免用空项目覆盖。默认项目公共认证为none，旧请求保持原认证行为。

项目数最多64，每项目最多32个环境、128个分类；HTTP请求总数最多512，项目/请求定义合计最多8MiB。每个作用域最多256个变量、合计1MiB，单值还有深度/256KiB估算限制；全部环境运行值有16MiB估算预算及条目限制。最多32行提取设置，禁用行同样计入编辑预算；变量展开最多16层/4096次，结果最多4Mi字符。

生产HTTP仍使用原cpr/libcurl客户端。TLS证书链与主机名校验、3xx保留、完整原始响应、默认预览遮蔽、有界历史和通信资源确认继续保留。工作流变量仍按流程运行隔离，HTTP项目变量不自动注入工作流或WebSocket。
