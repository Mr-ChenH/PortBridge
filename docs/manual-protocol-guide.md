# HTTP 与 WebSocket 手动调试

点击工作台上方“新建连接”（原始工作台侧栏加号也可），在六种类型卡片中选择HTTP或WebSocket。填写方案名称和完整地址，点击“创建并打开”即可保存到对应方案库并打开工作台。创建不连接、不发送；目标页面存在活动或未保存编辑时会保留或明确确认。直接在协议工作台点击“新建”仍可从草稿开始。

在“调试工作台”上方选择 **HTTP** 或 **WebSocket**。原来的串口、TCP客户端、TCP服务端、UDP位于“通信调试”，继续使用原连接方案。HTTP和WebSocket有各自的请求方案库。

HTTP选择方法、填写完整的 `http://` 或 `https://` URL，然后按需编辑参数、请求头、认证和Body。HEAD只读取响应头，不发送Body；选择HEAD后应将Body设为“无Body”。参数只追加启用的行；`+`、`&`、中文和emoji会按参数值编码。Body支持无Body、UTF-8原文、JSON对象/数组、urlencoded键值。JSON和表单模式自动补Content-Type，已有自定义Content-Type会保留。点击“发送请求”或Ctrl+Enter，等待真实状态码、耗时、正文大小及Body/JSON/Headers/HEX。401、404、500也会保留完整响应；网络、TLS、超时与容量错误单独显示。3xx保留Location，不自动跟随。

WebSocket先配置 `ws://` / `wss://` URL、握手请求头、认证、单个子协议（可选）；消息可在未连接时准备和保存，然后明确连接。连接不会自动发送草稿。连接期间握手配置锁定，仍可切换页签查看；选择UTF-8文本或HEX二进制，点击“发送消息”或Ctrl+Enter。文本不自动追加换行，支持空消息。HEX可用空白分隔，必须是完整字节；输入错误不会发送。TX表示本地写出，不能据此认定对端已经处理；RX保留服务端主动推送、完整消息边界、文本/二进制类型。断开默认发送1000关闭码，也可指定3000–4999及最多123个UTF-8字节的原因。时间线保留对端关闭码和原因。

暂停显示只冻结时间线，接收继续。清空只清除显示历史，不发送业务数据或断开连接。切换工作台类型、浏览方案、进入工作流或其他页面都不结束当前活动；开始另一类通信时，会明确确认是否结束旧活动。选择“保留当前活动”不会发送新请求。确认期间活动状态改变，需要重新操作。Escape取消正在请求、握手或关闭的操作，已连接的WebSocket请用“断开”。Ctrl+K聚焦当前协议URL。

默认响应或单条消息上限为1MiB，可在设置中改为1–8192整KiB；操作超时1–60000ms。请求Body/消息编辑最多1Mi字符。HTTP结果历史最多64项/16MiB估算预算，最新响应单独保留；WebSocket历史最多500项/4MiB。超过显示预算会明确提示未保留的历史，与网络丢包分别统计。原始文本/二进制按4095B分页，UTF-8分页保持完整字符；JSON采用最多32K字符的结构化遮蔽预览。较大的结构化消息、长凭据或无法安全检查的HEX会默认遮蔽，原始保留内容不被预览修改。

“保存方案”把请求加入左侧独立方案库；“导出”保存版本1 JSON方案，HTTP建议后缀 `.pbhttp.json`，WS建议 `.pbws.json`。方案最多64个、库/文件最多8MiB。默认保存会遮蔽认证、敏感参数/请求头/JSON字段，以及可能含凭据的二进制消息；不会改变当前编辑器内的真实值。载入含遮蔽标记的方案后，需要补填凭据才能发送。导入、载入、保存和启动都不自动通信；已连接时载入另一方案会保留当前连接并要求先断开。覆盖未保存编辑需要确认。

“复制预览”和“导出预览”只操作当前显示的、已经遮蔽的页，并在导出文件标注范围。HTTP/WS实际结果仍保留原字节和后端结构，不将默认预览当成原始抓包。TLS始终校验证书链与主机名；可提供CA文件，没有忽略证书选项，也不会自动重连、周期发送或保存真实认证值。

`docs/examples/local-http.pbhttp.json` 和 `docs/examples/local-websocket.pbws.json` 提供不含凭据的本地请求示例。它们引用的服务需由你自行启动，载入示例保持静默。

本次没有实现Socket.IO、SSE、OAuth交互登录、multipart文件上传、Postman集合兼容导入或多个同时活动的通信会话。原工作流的HTTP/WS节点继续使用同一生产协议实现，可用于组合调用、提取变量和断言。
