## 2. 打开方式

直接用 Chrome、Edge 等现代浏览器打开 `prototype/index.html`，无需 npm 安装、构建或启动服务。CSS/JavaScript/图标均在本地，不依赖 CDN。

默认展示一个正在运行的模拟 UDP 高速会话，以便立即评审数据工作区。这是原型初始场景，不能迁移为正式应用启动后自动连接或发送的行为。

## 3. 页面与交互

- 四种保存方案：串口、TCP 客户端、TCP 服务端、UDP。
- 单活动连接规则，切换方案停止旧连接和周期/记录任务。
- 参数编辑、合法性提示、模拟连接/断开/监听/绑定。
- TCP 服务端两个模拟客户端，支持指定目标和广播。
- 普通调试/高速采集模式切换。
- HEX/文本显示、来源/字节搜索、数据行与右侧字节详情联动。
- 暂停/恢复显示、清空显示、自动滚动及模拟样本 JSON 导出。
- 发送编辑、HEX 校验、附加换行、UTF-8 编码和字节数预览。
- 周期发送，持续/10/100/1000 次；运行中配置锁定，停止后恢复；断线停止。
- 命令添加、删除、载入；载入不会自动发送。
- 模拟原始记录、采集设置、容量估算与文件页。
- 深色/浅色切换，Ctrl+K、Ctrl+Enter 及基本键盘操作。
- 新建连接方案和命令编辑对话框。

主题和命令库可保存于浏览器 localStorage；连接方案、采集会话及统计仅在当前页面内存在。

## 4. 状态评审

状态栏中的“原型场景”为独立演示控制，不是正式产品功能。可选择正常流量、接收过载、记录变慢、连接中断。

- 正常流量：显示模拟吞吐和采样记录。
- 接收过载：横幅提示应用丢弃，队列接近上限，诊断数据更新。
- 记录变慢：记录运行时显示模拟写速不足及队列积压；记录未开启时提示启动后再观察。
- 连接中断：连接状态改变，发送与记录禁用，旧周期任务停止。
- 空状态：清空数据后展示等待下一条数据提示。
- 错误状态：非法 HEX、奇数位、不合法端口等显示内联提示。

吞吐、包率、序号缺失、网卡、设备、磁盘空间和采集文件容量全部为模拟。网卡/内核丢失显示“未知”，记录未开启时不宣称完整记录。

## 5. 浏览器验证

使用本机 Chrome 和 browser-tools 所安装的 Puppeteer 进行自动交互检查，另读取截图检查视觉布局。验证脚本位于 `.pi/ui-review.cjs`，依赖本环境中的 browser-tools 和 Chrome 路径，不是产品运行依赖。

执行：

```bash
node --check docs/project-factory/prototype/app.js
node .pi/ui-review.cjs
```

结果：通过，未捕获页面 JavaScript 异常。

已覆盖 17 组检查：

1. 四种连接及单活动会话切换。
2. UDP 已绑定的状态语义。
3. 数据选择与右侧详情联动。
4. 丢失诊断与未知系统计数。
5. 接收过载、记录变慢、断开场景。
6. 采集设置运行中锁定、停止后恢复。
7. 暂停显示期间模拟接收继续，显示内容冻结。
8. HEX 奇数位禁用发送，附加 CRLF 的字节数正确。
9. 周期发送可停止，断开时自动停止。
10. 有限周期准确结束：3 字节 payload + CRLF，共 10 次增加 50 字节 TX；配置锁定/恢复。
11. 导出的 JSON 明确 simulated 和 displayed-samples-only，含模拟数据。
12. TCP 服务端指定客户端和广播目标。
13. 命令新增、载入、删除。
14. 新建方案不自动建立连接。
15. Ctrl+K 聚焦搜索。
16. 深色/浅色主题切换。
17. 四种视口尺寸无整页横向溢出。

| 视口 | document scrollWidth | 结果 |
| --- | --- | --- |
| 1440×1000 | 1440 | 通过 |
| 1280×900 | 1280 | 通过 |
| 1024×768 | 1024 | 通过，连接面板可收起 |
| 390×844 | 390 | 通过，窄屏仅供评审，表格自身可水平滚动 |

六张截图对应深色、浅色、诊断、记录异常、串口、窄屏。记录/详情内部允许滚动，不把局部滚动误判为页面溢出。

## 6. 原型边界与后续事项

- 没有串口、网络 I/O、真实文件采集或性能验证；不会访问真实设备或写入显示的 D:\Captures 目录。
- 可下载的小型 JSON 包含模拟样本；不会生成列表中显示的 GB 级文件。
- 模拟连接立即完成；连接中/取消、设备权限错误及真实拔插由正式 Qt 实现验证。
- 模拟数值用于布局和状态评审，不能作为 2.5G 吞吐或零丢失证据。
- 记录目录、轮转和时长控件用于配置流程评审，原型未执行真实轮转/定时采集。
- 普通模式也使用有限模拟数据集；详细显示上限及高速 UI 性能需真实实现后压测。
- 窄屏调整仅便于浏览设计，当前产品仍为桌面工具。
- 实现前需在 Qt 下核查字体大小、125%/150% DPI、平台控件、中文输入法、原生焦点与快捷键。

下一阶段可按 `04-ui-design.md` 的组件映射建立 Qt Widgets 主窗口和界面组件，再连接独立通信核心；不把浏览器原型直接嵌入应用。
