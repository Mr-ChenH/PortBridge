# HTTP 项目工作台第一期要求

用户已以“继续实现”授权。本轮在已交付Qt工作台中实现项目化HTTP联调，保留原始串口/TCP/UDP、WS与工作流行为。

| ID | 要求 |
|---|---|
| HP01 | 本地项目创建、改名、删除；文件夹分类请求，归属以稳定ID记录；旧HTTP请求进入默认项目。 |
| HP02 | 每个项目有独立环境，创建/复制/删除/切换；普通定义变量持久化，敏感值和响应提取值仅运行期保存并可清除。 |
| HP03 | URL、参数、请求头、认证和Body支持双大括号变量；保存未解析模板，发送解析快照；未定义、循环/超限或无效结果在网络前拒绝。 |
| HP04 | 项目默认认证与请求继承/无认证/Bearer/Basic；登录可禁用继承；显示认证来源，重复Authorization不能静默覆盖。 |
| HP05 | 后置提取规则可将JSON字段/响应头保存为指定变量；敏感标志默认用于token。仅匹配成功响应、正确项目/环境/操作身份时提交更新。 |
| HP06 | 变量与token来源/更新时间可见、默认明文遮蔽；日志/复制/导出不得因变量替换暴露secret。 |
| HP07 | 项目定义版本化导入导出，默认省略敏感值；旧请求文件兼容，原协议类型schema不变。 |
| HP08 | 项目/环境/请求编辑与载入不触发通信；活动期间防止编辑运行身份，退出/覆盖保留原有确认；网络资源继续互斥。 |
| HP09 | 有界项目数、请求数、文件/变量/提取/预览；解析和存储先验证再修改，不用UI预览作为权威提取来源。 |

验收场景：新建项目及两个环境；保存登录与查询请求；登录真实返回 `data.access_token`，提取为敏感变量；查询以继承Bearer发送完全相同的token；另一项目/环境不可读取它；编辑token引用和base_url不影响已发送快照。401、缺失路径、无效JSON、取消/晚回调不更新token；token中引号/反斜杠/中文与query加号通过真实服务验证。项目导出无明文secret、重新载入需要补填/登录；旧请求加载及五个UI相关套件继续通过。

本期不提供任意脚本、OAuth交互授权、自动刷新/重登、云团队权限、多并行活动或生产系统真实登录。所有演示和验证使用本地测试服务与合成凭据。
