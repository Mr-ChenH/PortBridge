# PortBridge 审核修复与验收：audit-fix-1

本轮修复了 [原始审核](design-function-audit.md) 的 A01～A07、G01～G04，以及所列界面结构和交互差异。原始报告、失败探针和截图保留为 `ui-refinement-2` 的历史证据；当前可执行文件与便携包修订标识为 `audit-fix-1`，产品版本仍为 0.1.0。

修复后的 [设计 / 修复前 / 修复后对照页面](../validation/audit-fix/comparison.html) 可切换 8 个页面和两种基准。原生界面使用真实本机数据；没有将原型中的模拟设备、吞吐、磁盘能力或采集文件写入产品。Windows 原生深浅主题、1440×1000 和 1100×760 截图已由协调者实际查看。

## 界面修复

- 连接按钮紧随基础参数且位于高级设置上方；TCP 客户端按目标地址、目标端口、本地地址排列，本地端口移入高级设置。方案编辑/保存/导入导出保留在更多菜单，侧栏不再被额外工具条下推。
- 保留只读协议标签；侧栏没有“通信方式”输入。创建/编辑方案对话框仍提供协议选择。
- 状态徽标、数字字体和小标签更紧凑；显示格式回到显示提示行，必要的搜索语义、文本流、暂停和独立统计重置继续可用。
- 检查器为紧凑 OFFSET/HEX、明确预览范围、独立 ASCII；默认展示前 32 字节并可同时看到 ASCII，完整原始字节仍可复制。不把预览强调当作协议解析。
- 采集目录使用垂直标签，轮转/时长并列，容量估算有独立强调；真实磁盘空间通过后台查询，持续写入能力未测时仍显示未知。
- 诊断采用紧凑分隔行，并增加独立截断层；命令/采集页提供行内操作、右侧页头操作，命令区提供真实快捷命令按钮及更多/历史入口。
- 编辑对话框使用中文按钮、垂直字段、可见正文标签及提示；HEX 隐藏不适用的编码项，换行“none”显示为“无”而保持存储兼容。

本轮截图复核另外发现并修复了自定义行与 delegate 重复绘字、连接按钮深色对比度不足、ASCII 被大块留白推到折叠区域、更多按钮图标不清楚、小窗口侧栏空间分配问题。上述修复均在最终截图中复核。

原型示例名称、假数据、模拟速率不会与真实运行一致；额外必要功能通过更多菜单、行内操作和滚动区域保留。本次对齐是原生 Qt 的结构、信息层级和操作方式对齐，不宣称浏览器与 Qt 字体渲染逐像素相同。

## 响应性与新增复核发现

显示样本导出改为一个有界后台任务，快照持有原始字节，转换/文件写入不在 GUI 线程执行；支持取消和原子提交，失败/取消保留旧输出。卷空间查询使用独立有界任务，旧路径结果不能覆盖新路径。工作线程不引用 QWidget，窗口退出时取消并有限等待，病态 OS 调用仍可能在独立状态中延后结束。

独立审查进一步复现并修复两项边界：

1. 无效 sidecar 含非法开始时间和 999 秒时长时，原 fallback 仍保留未验证时长；现在先清空不可信数值，再从固定 raw 头尾恢复可验证字段。
2. `start()` 的直接 Qt 信号订阅者若在 Connecting 时切换配置，原 start 可能继续绑定旧 UDP 端口；现在发出信号后重新核对代次与 wanted。真实独占端口绑定复现已通过。

这两项由独立 reviewer 在协调者明确授权后修复，不能称为其完全独立的自审结论；协调者另外检查代码并执行未修改的原复现，[4/4 通过](../validation/audit-fix/coordinator-session-reproducers.txt)。其余会话实现由不同作者独立审查。

最终 root 回归还暴露了一处原测试时序假设：UDP Bound 在目标解析/发送就绪之前发出。仅将 wrap 测试的首次发送改为带锁存的 admission 等待，避免重复发送；精确四个接收和缺失/乱序断言保留，产品语义未改。
