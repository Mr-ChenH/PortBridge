# 会话浏览、文本预览与完整字节查看（interaction-fix-1）

按用户本轮反馈修复三项交互。版本仍为 0.1.0，交付修订为 `interaction-fix-1`；此处的新会话浏览规则取代旧报告中“选择方案即停止旧会话”的规则。原始用户请求包含 UDP 绑定、文本收发颜色/内容格式化、ASCII 显示完整性，本轮由当前协调者直接完成，没有新增子 agent。

## 1. 浏览方案保持活动 UDP

选择其他方案仅切换查看/编辑对象，原本的 UDP socket、周期任务、统计和记录继续运行。返回活动方案后恢复已有样本、文本、输入参数，并消费离开期间进入有界显示队列的数据。活动方案保留运行标记，浏览其他方案时底部显示后台端点与 RX 量；其他方案的页面不显示旧会话的数据、错误或统计。

仍只允许一个活动通信会话。显式解绑/断开、主动启动其他方案、编辑/删除活动方案、导入替换全部方案和关闭窗口会结束旧会话。新增方案、编辑/删除其他未运行方案不会结束后台活动会话。后台记录的采集目录仍由活动控制器提供，记录期间的删除保护继续生效。

实现使用一个保留的活动控制器/有界模型/文本文档，以及一个复用的离线浏览控制器；没有每点击一个方案就创建新会话。窗口销毁停止保留的控制器，控制器信号接收者与 UI 实现对象同寿命。后台显示队列达到原有上限时仍可能省略显示样本，原始记录和统计继续独立运行；返回时真实记录间断会提示解码状态重置，不宣称无限缓存。

真实 UDP 回归验证同一本地端口、同一会话代次，离开前 6 B 与离开期间 10 B 共 16 B 均可恢复查看；另一个 socket 无法独占绑定该端口。后台记录持续，采集页禁止删除活动文件，关闭窗口后实际端口可重新绑定。既有周期测试改为验证浏览时持续发送、主动启动另一方案后停止，未删除周期停止和计数断言。

## 2. 文本预览

RX 使用绿色、TX 使用蓝色，深浅主题分别使用可读颜色；每条内容附带软件时间、收发方向、端点和实际长度。颜色由实际 DataRecord.direction 传递，不根据内容中的“RX/TX”文本猜测。内容使用纯文本插入，`<tag>` 等原文不作为 HTML 解析。

格式选择立即作用于保留样本：

- UTF-8 原文：TCP/串口继续按来源和方向保留跨读取块解码状态，UDP 保留每包边界。
- HEX：每行 16 字节，显示实际字节。
- JSON 格式化：完整有效的对象/数组按缩进展示；无效 JSON 或跨读取块尚不完整的 JSON 保留原文，不冒充完整协议重组。

文本预览保持约 1 Mi 字符 / 10,000 文本块的界限，超限明确提示裁剪。格式化只改变展示，原始样本、复制和导出不变；高速采集模式仍只保留有限样本，不在接收热路径生成完整文本预览。

真实 UDP 测试逐字节核对发送内容，并直接检查 QTextDocument 中 RX/TX 字符的不同前景色及切换主题后的颜色。JSON 缩进、HEX 行内容、无效 JSON 原文回退均验证；既有 UTF-8 半字节序列、重置统计和真实记录缺口回归保留并通过。

截图：[深色格式化文本](../validation/interaction-fix/formatted-text-dark.png)、[浅色格式化文本](../validation/interaction-fix/formatted-text-light.png)、[返回活动 UDP](../validation/interaction-fix/retained-udp-session.png)。

## 3. ASCII/HEX 完整内容

删除前 32 字节硬截断。右侧提供 HEX / ASCII 页签，默认 ASCII；每页 4096 B，页内可滚动，更大的记录通过上方页码访问所有字节。小于 4096 B 的数据报整包显示在一页中。范围标签使用真实字节偏移，HEX 行偏移与滚动同步，非可打印 ASCII 字节以点表示。选择另一条记录、过滤失选或清空后重置分页和详情；复制按钮继续复制完整原始 HEX。

回归使用实际 6112 B UDP 数据报，检查第一页与第二页逐字节一致、页边界、第二页偏移 4096、末尾 `TAIL-visible`、光标末尾位于可见 viewport 内，以及整包复制。1472 B 检查从旧的“32 B”断言更新为全部 1472 B 和 184 行 HEX，并保留零横向溢出的断言。

截图：[完整 ASCII 的最后一页及末尾](../validation/interaction-fix/complete-ascii-tail.png)。ASCII 仅表达单字节可打印字符；中文等内容应在 UTF-8 文本预览中查看。

## 验证与交付

最终结果以 [CTest 日志](../validation/interaction-fix/ctest.txt)、[验证状态与源稳定性](../validation/interaction-fix/result.json)、[源哈希](../validation/interaction-fix/source-hashes.json) 为准。完整网络 10 组、会话 27/27、UI 34/34；Qt Test 总数包含初始化/清理。

Windows 原生专项在 [100%](../validation/interaction-fix/native-1.txt)、[125%](../validation/interaction-fix/native-1.25.txt)、[150%](../validation/interaction-fix/native-1.5.txt) 各 6/6，通过内容为上述两项综合回归、1472 B HEX/ASCII 宽度、原生页面/小窗口布局取证，含初始化/清理。截图已实际打开检查。软件缩放仍不等同真实多显示器 DPI 切换验收。

构建与多个原生测试曾在一次工具调用中合计超过超时限；拆开后验证通过。中间有一轮测试全通过但源哈希变化，未作为最终认证；后续冻结源文件后重新构建、验证。修改旧测试的范围为用户明确变更的“浏览保持会话”和“完整 ASCII”行为，其余断言保留。

新版运行路径：`dist/PortBridge-interaction-fix-1/PortBridge.exe`。旧目录和运行中的旧程序保留，避免中断用户会话。ZIP 仍为 `dist/PortBridge-0.1.0-windows-x64.zip`，前版已备份到 `build/package-backups/udp-fix-1/`。打包验证 Release/部署/解压 EXE 一致、全部文件哈希、独立运行环境启动及真实 UDP/TCP 各 500 帧回环，最终 ZIP 证据在 `docs/validation/interaction-fix-zip.json`。

当前证据不增加物理串口、双机 2.5G、持续磁盘负载、干净 Windows 或病态 OS 阻塞退出的验收结论。
